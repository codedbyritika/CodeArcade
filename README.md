# 🎮 CodeArcade

CodeArcade is a collection of interactive mini-games built using HTML, CSS, and JavaScript.  
The purpose of this project is to strengthen core programming concepts and create engaging web-based games.

---
## 🎯 Games Included

### 1. Simon Says Game
A memory-based game where the player repeats the sequence generated by the system.
🔗 https://codedbyritika.github.io/CodeArcade/tic-tac-toe/

### 2. Tic Tac Toe ❌⭕
A classic 2-player game where players take turns marking X and O to win.
🔗 https://codedbyritika.github.io/CodeArcade/simon-say-game/
