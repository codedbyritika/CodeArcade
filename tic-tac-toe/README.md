# ❌⭕ Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

Players take turns marking X and O on the grid.  
The game detects wins, draws, and allows restarting the game anytime.

---

## 🚀 Features

*  Two-player gameplay
*  Win detection logic
*  Draw detection
*  Reset game functionality
*  Sound effects
*  Winner GIF animation
*  Simple and clean UI

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript

---

## 🎯 How to Play

1. Player X starts first
2. Click on any empty box to place your mark
3. Players alternate turns
4. First player to match 3 in a row wins
5. If all boxes fill without a winner → Draw
