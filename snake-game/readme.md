# Snake Game

A classic Snake Game built using HTML, CSS, and JavaScript. The player controls a snake that moves across a grid, collects food to grow longer, and avoids collisions with the walls and its own body. The game features score tracking, sound effects, and smooth animation using JavaScript's game loop.

## Features

* Classic Snake Game mechanics
* Real-time score tracking
* Food generation at random locations
* Snake growth upon consuming food
* Collision detection with walls and snake body
* Background music and sound effects
* Smooth gameplay
* Responsive grid-based design

## Technologies Used

* HTML5
* CSS3 
* JavaScript

## How to Play

1. Open the game in your browser.
2. Press any arrow key to start.
3. Use the arrow keys to control the snake:

   * ↑ Up
   * ↓ Down
   * ← Left
   * → Right
4. Eat food to increase your score and grow the snake.
5. Avoid hitting the walls or colliding with the snake's own body.
6. The game resets after a collision.
